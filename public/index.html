    Pair Device

    Wireless Debugging Pairing establishes a trusted connection between this PC and the Android device. The device displays a 6-digit pairing code and a pairing port — enter them below.

    This is different from ADB Connect, which connects to an already-enabled TCP ADB endpoint (e.g. port 5555). Pairing is only needed once per device; after that, Connect is sufficient.
